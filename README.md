# 🍷 Wine Dataset Analysis using Python

## 📖 Overview
This project performs **Exploratory Data Analysis (EDA)** on a wine dataset using Python in a Jupyter Notebook.  
The goal is to understand the structure of the dataset, identify patterns, and analyze relationships between different wine features.

---

## 🚀 What I Did
- Loaded and explored wine dataset in Jupyter Notebook  
- Performed data cleaning and preprocessing  
- Conducted Exploratory Data Analysis (EDA)  
- Analyzed relationships between wine features  
- Visualized data using graphs and plots  
- Extracted insights from chemical properties of wine
